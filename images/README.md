# Screenshots

Add the following screenshots here (PNG, ideally 600-800px wide):

- `screenshot.png` — main hero screenshot for the README header
- `screenshot-day.png` — daytime view (sun up, battery charging, all flows active)
- `screenshot-night.png` — nighttime view (sun hidden, battery discharging)
- `screenshot-wallbox.png` — wallbox actively charging with mode badge visible

To take clean screenshots:
1. Open the card in your dashboard
2. F12 → device toolbar → set width to ~520px for the card view
3. Right-click the card → "Screenshot node" (or use browser screenshot tools)
4. Crop if needed
